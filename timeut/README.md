# timeut

Time Utilities

- Parse RFC3339
- Convert Unix 2 Time
- Convert Unix 2 Time String
- GMT Time
- Add time
- Subtract time
- Diff time
- convert to 24hr
- millis since epoch
- Julian 2 Date
- Date 2 Julian

## Additional Helpers

- `StartTime` and `StartDate` for week-based date calculations
- `Time(...)` and `GMTTime()` wrappers around the custom `MyTime` type

## Development

- `cd timeut && go test ./...`
