# appname

Sample application content used by the `mymg/test` project definition.

## Purpose

This directory shows the file layout that `mymg` expects when a project entry points at a `cmd/<name>` tree:

- `VERSION.txt` for the release version source
- `README.md` for release notes and published metadata references
- optional `CHANGES.txt` or full changelog files when changelog automation is enabled

## Usage

Use this tree as a template when wiring a new project into `mymg/test/build.toml`.
