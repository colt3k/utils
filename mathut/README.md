# mathut

Provides utilities to convert formats and work with common numeric calculations.

## API Surface

- rounding and formatting: `Round`, `FmtFloat`, `FmtFloatWithPrecision`, `FmtInt`
- parsing: `ParseFloat`, `ParseInt`, `IntSize`
- statistics-style helpers: `Percentile`, `Median`, `PercentDiff`
